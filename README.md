# Yerim Var

İzmir için boş otopark bulma uygulaması (iOS, Expo). Gideceğin yeri yaz, çevredeki otoparkları boş yer sayısı, ücret ve yürüme süresiyle gör.

> Durum: tasarım aşaması. Uygulama kodu henüz yok; geliştirme planı [`docs/PROMPT.md`](docs/PROMPT.md) içinde.

*English: Yerim Var ("I've got a spot") is an open-source iOS app for finding free parking spaces in İzmir, Turkey, using the city's open data.*

## İçerik

- `design/` — referans ekran tasarımları (PNG + HTML) ve ikonlar
- `assets/brand/icon.svg` — uygulama ikonunun kaynağı
